# 墨羽 丸コード 35 NF / Suminoha Maru Code 35 NF

欧文648：漢字1080、幅比3：5のコード用フォントです。Regular・横組み用で、主書体とHan JP・Han RareA・Han RareBの4書体を組み合わせます。TTFはデスクトップ用、WOFF2はWeb用です。

## 使い方

4書体をインストールし、アプリでは「墨羽 丸コード 35 NF」または「Suminoha Maru Code 35 NF」を選びます。ファイルを直接読み込む場合は、主書体 → Han JP → Han RareA → Han RareBの順で指定します。補助漢字の自動選択はアプリや環境によって異なります。

通常の欧文幅は648、漢字・全角空白は1080、半角仮名は540です。行メトリクスは1200／−350／行間0です。Code35には3：5の送り幅を扱える描画環境が必要で、一般的な1：2端末用フォントではありません。

NFは限定された端末アイコン集合を指し、完全なNerd Fontsではありません。カラー絵文字やZWJ列への完全対応はありません。補助漢字には、丸い主書体と字形・濃さが異なる文字があります。

収録範囲はパッケージ全体で105719文字、対象のUnicode17 Unified_Ideographは101996/101996、互換漢字は1014/1014です。IVS・地域別漢字・縦組み・全Unicode・任意の結合文字・すべてのアプリや端末への対応は保証しません。Pangoなどが互換漢字を正規化する場合があり、cmapの収録だけでは元の字形の表示を強制できません。

## 元フォントからの再生成

リポジトリ直下で `python3 scripts/rebuild_fonts.py` を実行します。別の出力先で確認する場合は `--out /tmp/suminoha-fonts` を付けます。元フォントから再生成し、ハッシュとシェーピングを検証して出力します。

出典・固定情報は `SOURCES.md` と `inputs/build-recipe.json`、パッケージのファイルとハッシュは `manifest.json` を参照してください。再配布には `licenses/` のライセンスと帰属表示をすべて同梱します。著作権・ライセンスの原文と、上流の名称制約を保持します。
