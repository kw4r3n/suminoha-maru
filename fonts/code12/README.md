# Suminoha Maru Code 12 NF / 墨羽 丸コード 12 NF

Regular・横組みのコード用フォントです。欧文と通常の空白は540、漢字と全角空白は1080の幅を使い、幅比は1：2です。Code35の欧文648：漢字1080（3：5）とは区別してください。

## ファイルと使い方

主書体とHan JP・Han RareA・Han RareBの補助漢字を組み合わせます。直接ファイルを読み込む場合は、主書体 → Han JP → Han RareA → Han RareBの順で指定してください。補助漢字だけではASCIIや仮名を含む主書体の代わりにはなりません。

Code12の主書体は、欧文と漢字の幅比を1：2にしたコード用フォントです。補助漢字の形・glyph ID・cmapはCode35と共通で、SPACE/NBSPの幅を648から540に合わせています。行メトリクスは1200/−350/gap0です。

プログラミング合字と元フォント由来の選択字形を保持します。NFは既存の限定アイコン集合であり、完全なNerd Fontsを意味しません。対応する機能は実フォントのGSUBと紹介ページで確認できます。

## 再生成・検証

リポジトリ直下で実行します。

```sh
python3 scripts/rebuild_fonts.py
```

別の出力先で確認する場合は `--out /tmp/suminoha-fonts` を使用します。入力・出力のSHA-256は `manifest.json`、有限な検証結果は `validation.json` に記録します。各書体のライセンス・帰属表示は `licenses/` を参照してください。

## 制約

1：2の幅比は、すべての端末のカーソル・セル表示の保証ではありません。IVS・地域別漢字・縦組み・全Unicode・任意の結合文字列への完全対応も保証しません。補助漢字には日本語の主書体と異なる形や濃さの文字があります。

本文の字間調整は別の [本文用フォント（バージョン0.008）](../gothic/README.md) に含まれます。Code12/35の固定幅へ本文用の追加字間を適用しないでください。
