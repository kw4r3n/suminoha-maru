# 本文用丸ゴシック / Suminoha Maru Gothic

英語の書体名は **Suminoha Maru Gothic**、日本語名は「墨羽 丸ゴシック」です。Han JP・Han RareA・Han RareBの補助漢字を組み合わせます。4書体ともバージョンは0.008です。Code35・Code12は、それぞれ幅比の異なる別のパッケージです。

1000UPEMで、字間調整の対象となる通常の基底グリフの送り幅に20単位（0.02em）を加えています。輪郭、グリフID・cmap、GSUB、GDEF・キャレット位置、縦方向のメトリクス、既存のGPOSルックアップは変更していません。漢字は1000→1020、SPACE・NBSPは261→281、全角空白は1000→1020です。Aは733→753、qは587→607です。元の送り幅が0のグリフは0のまま、半角濁点・半濁点の既存の正の送り幅500もそのままです。行メトリクスは1150／−350／行間0を維持しています。

合字では、元になる字間調整対象の基底グリフ数に応じて送り幅を増やします。fi・flとオランダ語のIJ・ijは40、No.由来の番号記号は60を加えます。アクセントやギリシャ文字の結合文字を合成する合字では、結合文字を0として数えるため、字間を重複して加えません。単一置換・選択字形への置換でも構成要素の数を引き継ぎます。字形を引き伸ばしたり機能を無効にしたりせず、元の合字を維持します。符号化済みのfi・fl・番号記号も同じグリフを使うため、複数文字分の増分を引き継ぎます。合字内部の輪郭とキャレット位置は元のままです。描画側でUnicodeの各書記素に個別に字間を加える処理とは同一ではありません。

既存のmark機能にPairPosルックアップを1つ追加し、半角濁点・半濁点が1つ続くときは、その後ろに追加の字間を移します。これにより `ｶﾞ`・`ﾊﾟ`・`ｳﾞ` の内部の結び付きを保ちます。対象は、2番目のグリフがこの濁点・半濁点のどちらかであるペアだけです。元の結合文字の配置とカーニングのルックアップは保持しています。q＋分音記号、x＋曲アクセント＋鋭アクセントなどの通常の結合列では、結合文字の絶対位置を維持します。結合文字の配置を明示的に無効にした場合、不正な半角濁点の繰り返し、未対応の結合文字、その他の未検証の文字列は保証しません。

## 表示上の注意

アプリ側の追加字間は0を基準にしてください。フォントの送り幅には行末の増分も含まれ、描画側の字間設定とは行端や合字の扱いが異なります。

整数位置で描画する環境では、小さな字間の増分が丸めによって見えなくなることがあります。更新後も古い表示が続く場合は、アプリを開き直してください。

## 元フォントからの再生成

リポジトリ直下で `python3 scripts/rebuild_fonts.py` を実行します。別の出力先で確認するときは `--out /tmp/suminoha-fonts` を付けます。

すべての工程と検証が成功し、出力ハッシュが一致してから現行フォントを置き換えます。入力・出力の固定ハッシュは `inputs/build-recipe.json`、元フォントの出典は `SOURCES.md` を参照してください。各書体には帰属表示・OFL・Unicodeの原文をすべて同梱しています。

収録範囲はパッケージ全体で105365文字です。IVS・地域別漢字・縦組み・全Unicode・すべての描画環境への対応は保証しません。互換漢字は描画側の正規化によって表示される字形が変わる場合があります。
